# Сайт VATK — Высший агротехнический колледж

## Структура
```
index.html         — Главная
news.html          — Новости
specialties.html   — Специальности
teachers.html       — Преподаватели
schedule.html       — Расписание
documents.html      — Документы
admissions.html     — Абитуриентам (с формой заявки)
contacts.html       — Контакты
css/style.css       — Все стили и цвета
js/main.js          — Мобильное меню + подсветка активного пункта меню
images/logo.jpeg    — Логотип
```

## Как разместить (хостинг)
Это статичный сайт — на нём нет базы данных и сервера, всё уже готово. Загрузите всю папку целиком (сохраняя структуру) на любой хостинг:
- **Бесплатно:** GitHub Pages, Netlify, Vercel — просто перетащите папку на сайт netlify.com/drop.
- **Обычный хостинг:** загрузите содержимое папки в корень сайта (обычно `public_html`) через FTP/файловый менеджер.
- **Локальный просмотр:** откройте `index.html` в браузере — но для корректной работы меню лучше запустить локальный сервер, например `python3 -m http.server`, и открыть `http://localhost:8000`.

## Что нужно заменить перед публикацией
Отмечено на страницах жёлтой плашкой «Это пример…»:
- Название города и точный адрес (сейчас — «г. Город, ул. Примерная, 1»)
- Телефон и e-mail
- Реальные новости (`news.html` и блок новостей на главной)
- Реальный список специальностей, сроков обучения и лицензионные данные (`specialties.html`)
- ФИО и предметы преподавателей (`teachers.html`)
- Расписание по всем группам (`schedule.html`)
- Ссылки на настоящие PDF-документы вместо `#` (`documents.html`)
- Код встраивания карты (`contacts.html`)

## Форма заявки на странице «Абитуриентам»
Сейчас форма ничего никуда не отправляет — она только показывает сообщение в браузере (см. `js/main.js`). Чтобы заявки реально приходили, нужен один из вариантов:
- Простой сервис приёма форм без своего сервера (например, Formspree, Getform) — меняете `action` формы на их адрес.
- Собственный backend (Node.js/PHP/Python), который принимает POST-запрос и отправляет письмо или пишет в базу.

## Если понадобится админ-панель
Этот сайт полностью статичный — контент правится прямо в HTML-файлах. Если позже понадобится, чтобы сотрудники сами добавляли новости и документы без программиста, для этого нужен отдельный backend или готовая CMS (например, простое админ-приложение с базой данных) — это отдельная задача, дайте знать, если понадобится её спроектировать.
